My Projects

RADAR System

A working radar setup for detecting nearby objects.

Arduino Ultrasonic Sensor LED'S Buzzer Servo motor
+ click for details

The servo rotates 180 degrees with the ultrasonic sensor. When an object is detected within range, the buzzer sounds and a red LED is lighted. If not, a green LED is lighted.

Bus Seat Indicator

A system that shows which bus seats are free or taken.

Arduino Push buttons LEDs 7 segment display a toy bus (for the prototype)
+ click for details

In the prototype I included only 4 seats. When a button is pressed, a green LED is lighted and 3 is displayed, likewise for every button. When all the buttons are pressed, a red LED is lighted and 0 is displayed.

Missile Launcher

A mechanical launcher project exploring motion and control.

Arduino Motor drive Bluetooth module App (developed using MIT App Inventor) 2 servo motors High voltage generator Syringe
+ click for details

The missile is the syringe — we seal all the holes in it, then spray some sanitizer or perfume inside. A spark is created by the high voltage generator, causing a chemical reaction inside the syringe that produces air, which blasts the syringe into the atmosphere. The 2 servos align the target on the X and Y axis. The launcher itself is like a tank that can move forward, backward, left, and right. All functions are controlled by the app.
